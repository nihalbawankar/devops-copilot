 Copilot

AI-Powered Self-Healing Kubernetes Platform

## Overview

DevOps Copilot is a production-inspired platform that automates software delivery, monitors Kubernetes workloads, detects failures, and uses AI to assist with root cause analysis and safe remediation.

## Tech Stack

- AWS (EKS, ECR, IAM, VPC)
- Terraform
- Docker
- Kubernetes
- Helm
- GitHub Actions
- ArgoCD
- Prometheus
- Grafana
- Loki
- Alertmanager
- Python
- FastAPI
- OpenAI API
